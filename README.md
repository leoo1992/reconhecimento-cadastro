# Reconhecimento e cadastro facial

Projeto de estudo relacionado ao cadastro de pessoas e reconhecimento facial. O repositório contém a aplicação e seus arquivos de interface; consulte a estrutura de código para os módulos disponíveis.

## Stack
- JavaScript
- HTML e CSS

## Como executar
Consulte os arquivos de entrada do projeto e abra a interface em um navegador. Não há comando npm de inicialização documentado no repositório.
