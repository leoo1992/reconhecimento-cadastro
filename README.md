# reconhecimento-cadastro

Repositório de estudo identificado pelo tema de cadastro e reconhecimento facial. A branch atual contém arquivos de configuração, verificações automatizadas e testes de manutenção do repositório, mas não inclui uma implementação executável da aplicação.

## Stack e ferramentas
- Node.js para scripts de teste
- JavaScript / módulos ES para verificações automatizadas

## Como executar
Não há aplicação nem comando de inicialização configurado nesta branch. Os testes de manutenção podem ser executados com o runner nativo do Node.js:

```bash
node --test tests/*.test.mjs
```
